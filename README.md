# 🌌 The Celestial World

**The Celestial World** — это захватывающая 2D ролевая игра (RPG), действие которой разворачивается на загадочном магическом континенте «Нитралас». Мир населен двумя разумными расами: людьми и эльфами, и выбор расы в начале игры сыграет важную роль в вашей дальнейшей истории!

Каждый игрок обладает таинственным артефактом — **Селесис (CeleSys)**. Он помогает осваивать магические способности и использовать их как в бою, так и в повседневной жизни. Система играет ключевую роль в развитии персонажа и сюжете. 

Игроки погружаются в атмосферу фантастического мира, создавая уникального героя с разнообразными характеристиками, исследуя тайны континента и сражаясь с монстрами необычными способами.

---

## ✨ Особенности игры

- ⚔️ **Боевая система**: Сражайтесь с разнообразными монстрами, используя оружие ближнего боя и уникальные магические способности.
- 💬 **Система диалогов**: Общайтесь с NPC, узнавайте историю мира и получайте задания.
- 💾 **Сохранение и загрузка**: Удобная система сохранения прогресса (включая характеристики персонажа и свойства объектов) в формате JSON.
- 🎨 **Анимации и атмосфера**: Живые анимации персонажей и окружения, создающие эффект полного погружения.
- 🖥️ **Поддержка разрешений**: Игра оптимизирована для работы в разрешениях 1280x720 и 1980x1020.
- 👤 **Один герой — одна история**: Создайте своего уникального персонажа (человека или эльфа) и проведите его через все испытания.

## 🎮 Управление

| Клавиша | Действие |
| :--- | :--- |
| `↑` `↓` `←` `→` | Перемещение персонажа |
| `F` | Атака ближнего боя |
| `Alt` | Использовать магию |
| `Q` | Смена типа магии |
| `E` | Взаимодействие (общение с NPC) |
| `SPACE` | Пропуск диалогов |
| `J` | Открыть окно характеристик героя |
| `ESC` | Пауза и выход в меню |

---

## 🛠 Технологии и требования

Проект написан на **Python** с использованием современных библиотек для создания игр.
Основные зависимости:
- `pygame-ce` / `pygame-gui` / `pygame-widgets` — графика, звук и интерфейс.
- `numpy`, `Pillow` — работа с данными и изображениями.
- `python-dotenv`, `python-i18n`, `simplejson`, `xmltodict` — конфигурация, локализация и сохранение данных.

Для установки всех зависимостей используйте команду:
```bash
pip install -r requirements.txt
```
